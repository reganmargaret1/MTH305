    You should present solutions neatly to all problems, making sure to show all your work and follow the homework policies (see Blackboard document for details). You will turn in the assignment on Blackboard by 11:59 pm ET on Sunday. The solutions you turn in should be your own work and written in your own words. You cannot use any resources outside of discussing with your professor and/or classmates. No AI resources. At the top of your first page of solutions, please list the names of any students who you worked with on the assignment. Don’t forget to put your name at the top of the first page!

    1.

    Let’s create a random walk in one direction (you move forward or backward 1) with 100 steps. Let \(Y_i\) be independent random variables
    \begin{equation*} Y_t = \begin{cases}1 &\text{with probability } \frac{1}{2}, \\ -1 &\text{with probability } \frac{1}{2}.\end{cases} \end{equation*}
    🔗
    Let \(X_0 = 0\) and for all time \(t = 1, 2, \ldots, 100,\) let \(X_t = \sum\limits_{i=1}^t Y_i\text{.}\) That is, \(X_t\) is the sum of all of the \(Y_i\) ’s up to that point, which is the same as saying \({X_t = X_{t-1} + Y_t = X_{t-1} \pm 1.}\)
    🔗
    Graph the state variables \(X_0, \ldots, X_{100}\) with respect to time \(0, \ldots, 100.\)
    🔗
    Note: every time you rerun this code, the graph will look different since you are using random numbers.
    🔗
    Some hints:
    • Since you are finding a random variable for each time \(t\text{,}\) it may be useful to use a for loop, or a while loop, that loops through steps (that is the range, or the arange) 1, 2, ..., 100. So, ’for t in 1,2,...,100:’...
      🔗
    • It is a good idea to store the values of \(X_t\text{.}\) So before the loop, you should create a vector called \(X\) that is the size you need it to be. What size do you need it to be if we take 100 steps and also include step 0? Note below there is a vector \(X\) created already that defines an array of 5 zeros, how do you adjust it? (Since you will be replacing values, it doesn’t matter what that vector is - perhaps all zeros, all ones, so on.)
      🔗
    • You can create an array of zeros using the following command X = np.zeros(5).
      🔗
    • Since \(X_0 = 0\text{,}\) and \(X_0\) needs to be the first entry in the array \(X\text{,}\) make sure 0 is in the first entry of the array \(X\text{.}\)
      🔗
    • Then you need your loop. Within that loop you need to pick -1 or 1 randomly for \(Y_t\text{,}\) that is \(Y\) at that time step. There is a built-in function in the numpy package (and in the cell below) that finds a random integer between \(a\) and \(b\text{,}\) np.random.randint(a,b). Can you use that to define a \(Y_t\text{?}\) Note that \(a\) is included, \(b\) is excluded in the built in function. Note also that you want \(Y_t\) to be either 1 or -1, but not zero. So if you have Y = np.random.randint(0,2) for instance, it will choose randomly between 0 and 1. Can you use simple algebra (addition, subtraction, multiplication, division), to change that to between -1 and 1?
      🔗
    • Once you choose a random \(Y\) as 1 or -1, you can find \(X_t\) from \(X_{t-1} + Y_t\text{,}\) that is the previous term in \(X\) added to the \(Y\) at that step. So you need to change the correct entry of \(X\) to replace with the desired value, how do you specify a specific entry in an array? (Note: \(X_0\) is 0 already, so your first run through the loop has to put \(Y_t\) which is 1 or -1 in the second entry of the array, and python starts counting at 0).
      🔗
    • One you’re done with your for loop, that is outside your for loop, you want to plot the final array \(X\text{.}\) If you use the code plt.plot(X) where \(X\) is an array, it will automatically plot the x-axis as 0, 1, ... through the length of \(X\text{.}\)
      🔗
